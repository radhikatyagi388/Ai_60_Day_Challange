             # Day 1 - What Does an AI System Actually Do?

## AI Pipeline

User Input
      ↓
Input Processing (Tokenization)
      ↓
Large Language Model (LLM)
      ↓
Output Generation
      ↓
Final Response

## Three Real-World AI Products

### 1. ChatGPT
- Input: User prompt
- Processing: LLM understands and generates text.
- Output: Human-like response.

### 2. Google Translate
- Input: Text in one language.
- Processing: Translation AI converts it.
- Output: Text in another language.

### 3. Spotify Recommendations
- Input: Listening history.
- Processing: Recommendation algorithm.
- Output: Suggested songs.

## How a Chatbot Works

A chatbot receives a user's message as input. The text is tokenized into smaller pieces that the AI model can understand. The Large Language Model analyzes the context and predicts the best response. The response is formatted and checked before being returned to the user. This entire process happens in a few seconds, enabling natural conversations.
